# 中文课堂 TokenDance 钱包

> 主线调整后，中文课堂使用首页 `/`，授权回调也返回首页；`/zh-youth` 仍可访问。黑白熊 Demo 为 `/styles/monokuma`，其 API 与主课堂继续隔离。

当前主课堂与黑白熊兼容路由共用 TokenDance DeepSeek 4.1 Flash 脚本适配器，显式关闭思考。Gemini 调用和配置已移除。黑白熊 `/api/classroom` 仍使用独立的私有操作员凭证和原 fal 视频路径，不读取访客钱包；主课堂也不会回退到操作员 Key。此次接口调整不更改课堂材质或认定视觉已验收。

## 复用来源与协议

复用相邻开源工程 `ai-live-classroom` 的 TokenPay 钱包、规划、视频适配器，改为中文课堂专属路由、Cookie 和存储。不是只加一个钱包外观。

2026-09-22 只读核对官方文档及公开模型目录：

- [S256 PKCE 授权](https://tokendance.space/docs/api-key-oauth)：一次性 code 在服务器交换，绑定发起授权的浏览器；10 分钟过期。
- [开放平台余额](https://tokendance.space/docs/open-api)：微元换算成人民币；读取失败显示不可用，不能显示成零余额。
- [MiniMax V2](https://tokendance.space/docs/protocol-minimax-video-generation-v2)：视频任务提交一次，再查询任务；不自动重提、不切换服务。
- [公开模型目录](https://tokendance.space/gateway/v1/models)：核实 `deepseek-v4.1-flash` 与 `minimax-h3-max`。新课堂规划走 TokenDance Chat Completions；视频走其 MiniMax V2，5 秒、768P、16:9。

开场由同一次规划选择 15/20/25/30 秒，续课保留用户手选的 10 秒，不自动选续课。授权/余额读取不发生成请求；只有明确开始课程或选择续课才可能提交计费请求。真实金额以平台账单为准，不借用原 Demo 的 fal 估价；新课堂 API 的 `estimatedSpendCents` 返回 `null`。

## 隔离和部署

- `/api/youth/tokenpay/*`：授权、粘贴 Key、状态、断开。
- `/api/youth/classroom/*`：浏览器身份与钱包版本双重隔离。Key 断开或切换后，旧规划结果不能继续提交视频，也不能借新 Key 为旧队列付费。已提交的任务不能保证撤销或免计费。
- `youth_classroom_wallet`：随机身份 Cookie，HttpOnly、SameSite=Lax，HTTPS 部署加 Secure。所有写操作核对 Origin。
- `.youth-tokenpay/`：服务器 AES-256-GCM 加密 Key，身份参与认证；不发回浏览器、不进入 localStorage、URL、日志或 Git。此方案的加密密钥也在服务器磁盘，不等于硬件密钥链；生产部署需限制服务器访问并备份整个私密目录。
- 断开连接删除本应用保存的 Key，不会替用户撤销 TokenDance 平台上的 Key；平台 Key 的撤销仍由用户在平台管理。
- `.youth-recordings/<owner>/`：独立录制。中文付费生成要求开启 `SAVE_RECORDINGS`，以持久化提交意图与任务编号；关闭时不准入新的付费生成。回放只匹配本人的历史记录；新 `/api/youth/saved-video/*` 检查 Cookie，无公共录制目录混用。浏览器 Cookie 丢失后不能恢复原身份下的录制。
- 本地 loopback 自动使用当前端口；对外部署必须配置 `TOKENPAY_PUBLIC_URL=https://你的域名`。不根据任意外部 Host 自动信任授权回调。反向代理不要记录 callback 的 code 查询参数。
- 授权流程仍在当前 Node 进程内。课堂重启后可在原身份加载钱包时从磁盘重建已选择路径；只查询原任务 ID 并补下载，绝不自动补买未提交片段。新记录绑定钱包 Key 的不可逆指纹，换 Key 不用新钱包查询旧任务。多实例部署仍需共享安全身份、授权、预算和任务存储，不能直接横向扩容。

## UI 与性能

默认小入口，展开为不透明深色底板；金额等宽数字、清晰错误提示、密码型 Key 输入、至少 44px 按钮、Esc 收起并返回焦点。手机布局给底部课程输入留空，视频模式入口避开底部课程进度。未成年人明确提示由家长/老师授权和设置额度。

钱包为普通 DOM/CSS，不增加模型、贴图、阴影、后处理、持续动画或背景模糊。余额不循环查询：初次状态读取、手动刷新以及每节课程准入前预检；连接/断开更新空课堂会话，无需整页刷新。浏览器内不持久化用户粘贴的 Key，提交、关闭或错误后清空输入。

## 2026-10-01 流程恢复修正

- 视频 POST 仍只提交一次。合法 JSON 缺少 task/status、未知状态、缺少结果 URL、返回其他任务 ID 时，继续有间隔地查询同一编号，直到取得明确结果或到达截止时间；没有替换任务。
- 准入前通过公共人民币价格目录和本人余额核验整节预算：选择分辨率的保守价、脚本 token 上限、10% 余量。同一 Key 的并发课程共享本进程预算；读取失败关闭准入。未知付费状态继续占预算。该预算不是平台冻结，不能排除其他应用消费或账单延迟。
- 每节完整就绪才起播，手选续讲可在无浏览器播放时继续生成；最多两条手选续讲、两任务并发。失败停止新任务。退出仅停止后续提交，已受理任务仍可能计费并保存结果。
- 播放中刷新接回服务器当前片段；视频加载失败可“重新加载视频（不重新生成）”或退出，按钮位于普通页面提示层，不随远处电视缩小，最小高度 44px。服务重启从录制重建片段，不恢复精确播放秒数。
- 不完整记录先回收已有编号和视频，不静默退回付费生成；完整开场不再受不完整子课程阻塞。已有续讲按题目匹配复用，手选新分支只购买新增片段，并记录对原开场的引用，不改原完整历史。
- 按用户要求沿用黑白熊文字生成流程：每段重复同一角色表、声音、台词和日式 Q 版风格。候选图片不作为首帧；跨镜头身份和声音一致性尚无新版真实成片验收。

验证：129 项单测、类型检查、ESLint、生产构建及空钱包接口检查通过；浏览器恢复验证使用本地模拟媒体。未使用真实钱包、未提交付费规划或视频请求，也未部署。已知无法自动恢复的边界：平台受理后尚未写下编号就崩溃、原脚本未保存、从未提交的镜头、平台终止/过期任务、原身份或钱包丢失。

## 后续闭环复核

- 课堂建立、轮询、命令确认及退出均有网络超时保护。短暂断网或网关错误自动恢复；开始/续讲确认只重发同一命令编号，服务器及重建的录制去重，不重买课程。播放回执按序送达，迟到的状态不再重播已结束片段。重启后使用新的运行态编号，避免较低版本被当成旧状态丢弃。
- 视频查询的本地等待窗口结束不等于平台任务失败；仍按原编号继续查询。余额、报价与下载只对读取做有界重试，下载拒绝空文件或 HTML 错误页。录制尾行中断保留先前完整回执；脚本响应已存但整理结果未写完时，可从原响应重建，不再调用付费规划。
- 钱包先读取本地连接身份以接回课程，余额随后读取，避免平台余额接口拖慢正在播放的课程。准入预检期间退出，不再启动付费脚本；已被平台受理的任务继续收集结果，不能承诺撤销或免计费。
- 媒体加载与播放确认都有看门狗；短暂失败最多重读同一视频三次，仍失败时提供普通页面层的重载/退出按钮。浏览器限制声音时提示点击“播放课程并开启声音”。失败课程不会显示为完成或 100%。
- 对原编号缺失、从未提交镜头、终止/过期任务、身份或钱包不匹配，明确提示需用户处理，不无限显示恢复中，也不静默补买。已保存完整课程优先回放。最近一次有效视频地址用于回收核对，避免更新签名链接后被旧地址误判为不完整。

本轮验证：150 项单测、类型检查、ESLint、生产构建及 31 项空钱包接口检查；11 种后台浏览器恢复场景。另以真实课堂运行态和临时录制目录、完全模拟的提供方，完成 30+10+10 秒路径及 10 段连续播放（约 50 秒、最多两任务并发）。证据位于 `output/youth-recovery-qa/results.json` 与 `output/youth-flow-qa/results.json`。本轮未使用真实钱包，未提交真实付费脚本或视频请求，未部署；提供方真实产出、排队速度和扣费仍未验证。

## 验证边界

**内容驱动的开场时长：** 中文主课堂的开场选择 15、20、25 或 30 秒（3–6 个五秒镜头），由一次 DeepSeek 规划返回时长、理由、全部台词和动作。校验时长与镜头数量相等、单段台词符合五秒上限后才允许视频提交；不截断多余台词，不追加规划请求凑时长。原开场命令中的 30 是准入上限，不是最终时长。准入前仍按上限保守核验整节资金，规划完成后缩小本进程预留，视频提交数按实际分镜；无法保障其他应用消费或平台账单延迟。续讲仍为手选 10 秒，旧的 30 秒缓存不修改。

缓存视频回归分两类：原脚本与十段真实成片通过原生录播 API 验证完整历史课程；短时长测试只复用这些真实 MP4 作为媒介，规划/生成采用模拟提供方，不宣称新课程内容或 DeepSeek 实际选择已经通过付费实测。公开仓库只保留测试工具和边界说明，不上传个人录制、任务日志或钱包目录。

**对照原版的起播方式：** 原版 `internetphysics/live-classroom@5a07110` 一次规划所有五秒分镜、两任务并发、前两段解码后起播，并预载和交换视频槽位。主课堂移除等待整课完成的额外限制；已选的短课仍在后台收集结果，即使浏览器暂时不播放。预算按准入时核实的价格在本地缩减，保留脚本费用上限与 10% 余量，不在规划后重复读取价格/余额。每段请求的 `duration: 5` 与 Prompt 中的 Five-second、本镜头动作、逐字台词保持对应。原版也没有把前段末帧作为后段输入，不能据此保证生成画面、动作或音色完全连续；本次不新增逐镜头 LLM 调用、长视频生成或付费衔接修补。
