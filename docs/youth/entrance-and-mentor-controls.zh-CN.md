# 入场动画与轻量形象切换

更新日期：2026-09-22。按用户要求减轻形象切换入口，并参考原弹丸论破主题的“加载封面 → 揭幕 → 镜头到位”结构，适配当前中文二次元课堂。

## 形象切换

- 去掉“切换形象”可见文字、胶囊底色及边框，仅显示 20×20 的双向箭头 SVG。
- 保留 44×44 透明点击区域、动态中文无障碍名称、鼠标悬停说明和键盘焦点，不以缩小点击范围来减轻视觉重量。
- 男女素材、腰部透明渐变、选择状态、问题草稿及生成接口不改。

## 加载与入场

- 使用现有男/女生立绘、深墨绿背景和倾斜浅色图形制作中文入场封面。没有新图片生成、新模型、额外音频、实时阴影或后处理。
- 原先加载遮罩一直覆盖到镜头完成，导致用户看不到入场镜头。现在资源共享 Suspense 完成并预热三帧后，才发布 `entering`；遮罩用 0.32 秒淡出，再播放约 1.65 秒的轻下降与前推。
- 镜头沿用原主题的五次缓动与轻弧线思路，按当前房间缩小幅度；终点与此前大厅/电视构图完全相同，不穿过天花板。
- 镜头就位才显示输入框和钱包。加载失败显示重试入口；启用“减少动态效果”时跳过揭幕和镜头动画，资源就绪后直接进入。
- 封面人物只做一次轻落地；加载线条最多播放四次，不显示虚构百分比。进入课堂后整个封面从 DOM 删除，仍采用按需 WebGL 渲染。
- 该两秒左右是场景资源就绪后的入场时长，不是网络加载速度承诺；一次性动画有短暂绘制成本，不代表整机功耗完全不变。

## 检查方式

- 类型检查、ESLint、105 项单元测试、生产构建及 29 项免付费接口检查。
- 后台浏览器人为暂扣本地材质响应，确认真正加载完成前封面不会消失；在揭幕后捕获仍在运动的镜头，确认没有把动画藏在遮罩后。
- 检查桌面、手机、Retina、减少动态效果、材质加载失败、男女键盘/鼠标切换、TokenDance 钱包和本地模拟视频播放。
- 页面效果截图和机器结果位于被 Git 忽略的 `output/youth-qa/`：`entrance-desktop-loading.png`、`entrance-desktop-landing.png`、`entrance-mobile-loading.png`、`entrance-mobile-failed.png`、`desktop.png`、`browser-check.json`。
- 不调用真实课堂脚本或视频生成接口；本次只更新本地预览，未发布线上。

## 实测结果

- 上述类型、lint、105 项单测、生产构建、29 项免付费接口检查及后台浏览器检查均通过。
- 桌面/手机阶段顺序均为 `loading → entering → ready`；揭幕后捕获到镜头进度约 20%，到位后封面卸载。减少动态效果时为 `loading → ready`，不播放入场镜头。
- 正常场景浏览器错误为 0；本地模拟材质 503 时重试提示可见、按钮可用。手机加载封面和错误态没有横向溢出。
- 场景仍为 27 次绘制、40,072 个三角面，静止 3 秒新增渲染帧为 0，Retina 静止亦为 0；图标切换 API 写请求为 0，标题和输入框位置不变。
- 钱包、原黑白熊独立主题及本地模拟六段播放回归通过，未消耗课程生成额度。
