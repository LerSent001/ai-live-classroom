# Monokuma UI portraits

Unmodified transparent sprites from [LithiumWaves/danganronpa-sillytavern](https://github.com/LithiumWaves/danganronpa-sillytavern/tree/d565554d0d101f60a3ae383bd346f74e77afd65b/assets/monokuma), retrieved 2026-09-03.

- `standing.webp`: `assets/monokuma/monokuma_idle.png` (394 × 532)
- `laugh.webp`: `assets/monokuma/monokuma_laugh.png` (311 × 520)

The upstream files contain WebP data despite their `.png` extensions. Only the local extensions were corrected; image bytes are unchanged.

Monokuma and Danganronpa belong to Spike Chunsoft. No separate redistribution license for these character sprites was identified. These assets are used for the requested local visual prototype; the source repository is not evidence of a commercial character license.
